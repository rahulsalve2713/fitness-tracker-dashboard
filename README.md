# Fitness Tracker Dashboard

## Overview
An interactive fitness dashboard built using Tableau Public to visualize daily activity and health-related metrics across a 30-day sample dataset.

## Dashboard Features
- Total Steps
- Average Daily Steps
- Total Calories Burned
- Average Sleep Hours
- Daily Steps Analysis
- Calories Burned Analysis
- Heart Rate Analysis
- Sleep Analysis
- Activity Duration Analysis
- Interactive Date Filter

## Tools Used
- Tableau Public
- Microsoft Excel
- Data Visualization
- Dashboard Design

## Dataset
The project uses illustrative sample fitness data for a 30-day period.
